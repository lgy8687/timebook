# 时间记录设计登记表

开发者模式使用三类地址：

- `B` 定位整个功能块。同一种功能块重复出现时，共用一个 B 号。
- `Z<功能块号>-<序号>` 定位功能块内的子模块。同类重复项共用一个 Z 号。例如 B30 是整条底部导航，四个入口都属于 Z30-1。
- `C` 定位已确认的共用设计模板。模板同时包含外观、交互和允许的响应式变化；仅外观相似、交互不同的组件不能共用一个完整的 C 号。

徽标显示 `B14/C01` 或 `Z14-1/C02`，点击复制完整地址。编号以功能原型为依据，不随文字、日期或渲染顺序变化。

## 文字规范

| 层级 | 变量 | 默认字号 | 用途 |
| --- | --- | --- | --- |
| 一级标题 | `--ui-heading-1` | 20px | 页面主标题 |
| 二级标题 | `--ui-heading-2` | 17px | 页面主要分区 |
| 三级标题 | `--ui-heading-3` | 15px | 功能块和弹窗标题 |
| 四级标题 | `--ui-heading-4` | 13px | 紧凑面板标题 |
| 正文 | `--ui-body` | 13px | 操作项与简短说明 |
| 辅助文字 | `--ui-caption` | 11px | 日期、注释等辅助信息 |

字体沿用 `design-system.css` 中的平台系统字体。统计数值属于独立的数字层级，可以根据容器放大；颜色和字重可以表达状态，但相同文字层级应保持一致的基准字号和行高。新增界面优先使用上述变量。现有开发外观设置 `reportTitleSize` 可以统一覆盖报表功能块标题字号，不影响其他层级，也不改写用户已保存的设置。
