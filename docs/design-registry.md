# 时间记录设计登记表

开发者模式使用三类地址：

- `B` 唯一定位一个界面原型（围栏）：它圈定当前界面中固定的一组交互与内容结构，不表示业务名称。一个 B 不得对应两种界面组成；同一原型的重复实例（例如流水列表里的同类记录卡，只是数据和文字不同）可共用 B。点击后若界面组成或交互集合改变，即使复用同一个弹窗 DOM，也必须切换到新的 B。一个 B 的选择器可命中多个实例，仅限这些实例是同一原型的克隆，并显式标记 `repeatable`。
- `Z<功能块号>-<序号>` 定位功能块内的子模块。同类重复项共用一个 Z 号。例如 B30 是整条底部导航，四个入口都属于 Z30-1。
- `C` 定位已确认的共用设计模板。模板同时包含结构、外观、交互和允许的响应式变化；仅外观相似、交互不同的组件不能共用一个完整的 C 号。一个 B/Z 可暂时没有 C，但必须在确认模板后登记；不能为了补齐编号而误套模板。

每个 Z 必须归属于唯一 B。徽标显示 `B14/C01` 或 `Z14-1/C02`，点击复制完整地址。编号以功能原型为依据，不随文字、日期或渲染顺序变化。B 徽标选择器应命中一个功能区块；多个完全相同的重复实例可显示同一原型号，不得把多个不同功能区块放在一个选择器下。
B 徽标统一在功能块右上角，使用蓝色；Z 徽标统一在子模块左下角，使用绿色。弹窗关闭按钮等占用右上角时，B 徽标可在右上区域内避让，但不改到左侧。

语义角色从这套字号中选择：页面主标题 `1`，主要分区标题 `1.2`，功能块标题 `1.4`，紧凑标题与正文 `1.6`，辅助文字 `1.8`。字体沿用 `design-system.css` 中的平台系统字体；颜色和字重可表达状态，但同一角色应保持一致的基准字号和行高。统计大数字、图标与表盘刻度属于独立的展示元素，不按正文层级处理。

层级号只用于规范和审查，**不显示在界面文字后面**。开发者模式会在含文字的 DOM 元素上记录 `data-dev-type-level` 与 `data-dev-type-size`；不在字号表中的旧样式标记为“待归档”，便于以后定位，而不是悄悄归到相近级别。新增或调整普通文字时，必须从上表选一个字号变量。开发外观中的文字字号也按这些档位选择；已有档外自定义值保留为“旧设置”，不会因升级而改写。图标、表盘数字和容器尺寸不受文字档位限制。

## 自动检查

`Z34-1` 是随手记右侧的事件入口，打开与正在进行主线上的事件按钮相同的事件选择界面。
`B85` 是正在进行的未分配主线，`Z85-1` 是其事件入口；历史未分配主线仍为 `B50`。

在本地运行 `node --test tests/*.test.js`。编号测试会检查 B/Z 重复、Z 父级、C 登记、单区块选择器、补录全部界面状态到 B 的映射，以及报表视图状态到 B/C 的映射。开发者模式运行时还会检查 B 选择器是否意外命中多个元素，未声明可重复的 B 会在控制台报错；共享弹窗显示子模块徽标前会校验其父 B。当前仓库没有已启用的 GitHub Actions 测试门禁，因此合并或发布前须运行上述命令。重复流水卡片等原型必须在编号表显式标注 `repeatable`。

本版新增定位：`B34` 是首页随手记按钮与输入框组成的整体功能块。`B35`–`B41` 分别是七个不同的设置详情面板，虽然共享 C22 外壳，不能合并成一个 B。日报半日轴由 `B18/C23` 和 `B42/C23` 分别定位上午、下午；周报、月报、年报的周期构成图由 `B45/C24` 定位。报表渲染器按 `timeline.kind` 为当前卡片写入唯一 B 地址。补录弹窗根据可见界面状态切换 B；归属时段列表为 `B55`，其子模块为 `Z55-1/C05` 和 `Z55-2/C19`，不再错误挂在方式选择界面的 B11 下。补录表单按是否可更换归属、是否已有目标分别登记 B；来源相同不代表界面状态相同。流水卡片只有界面结构和交互一致、仅记录内容不同才共享 B；未分配卡、进行中卡和结转修改等不同交互使用独立 B。旧编号 `B20` 因曾同时指向七个面板而退役，不再分配。旧编号 `C17`、`C20` 已由统一模板 `C02` 取代，不再分配给报表分段选择器。

时间删除处理定位：`B81` 是已分配主线删除后的上下归并方向选择；`B82` 是未分配时段删除后的归并方向选择。只有流水卡片删除确认 `B83` 提供“清空”：移除分类记录、保留并行/事件数据，将时段恢复为未分配；其“删除”操作才进入 B81。点击弹窗外仅关闭弹窗。
