# 出车收支日历 · 改版设计文稿

> **文档用途**：发给本地 PC 端开发同事，作为界面重构与功能拆分的实施依据。  
> **设计理念来源**：TimeBook Pro（时间账本）v4.x 已验证的交互与信息架构。  
> **目标产品**：出车收支日历（网约车 / 多平台收入 + 支出分类）  
> **文档版本**：v1.0 · 2026-05-21

---

## 一、为什么要改

### 1.1 现状（截图中的产品结构）

当前产品以**单页 + 顶栏切换**为主，大致包括：

| 区域 | 现状 | 问题 |
|------|------|------|
| 顶栏 | 「日历视图 / 月度统计」两个 Tab | 与底部导航习惯不一致；「统计」不够独立 |
| 设置 | 右上角齿轮进入独立设置页 | 与 TimeBook 一致应迁入 **「我的」** |
| 日历 | 与统计挤在同一信息流里切换 | 应**单独成 Tab**，下方跟当日明细 |
| 统计 | 柱状图 + 平台/分类列表 | 缺**环图总览**；缺与 TimeBook 对齐的 **日/周/月/年** 报表结构 |
| 底部导航 | **无** 四栏底栏 | 用户已习惯 TimeBook：**首页 · 日历 · 统计 · 我的** |

### 1.2 改版目标（一句话）

**把「时间账本」已跑通的信息架构与视觉语言，映射到「收支日历」——钱和时间的结构对齐，四 Tab 分治，统计双环图，报表四周期。**

---

## 二、设计哲学（与 TimeBook 对齐）

### 2.1 核心问题

| 产品 | 用户一直在问的问题 |
|------|-------------------|
| TimeBook | **你的时间去哪了？** |
| 出车收支日历 | **你的钱从哪来、花到哪去？** |

结构同构：**一段连续生活 / 出车周期 → 切片查看 → 分类归因 → 周期报表。**

### 2.2 结构对齐原则

| TimeBook 概念 | 本产品的对应 |
|---------------|--------------|
| 双环时钟（短周期 + 长周期） | **收入环 + 支出环**（同一查看日/周期的「进」与「出」） |
| 流水（当日记录列表） | **首页 / 日历下方** 的收支明细行 |
| 日历（选日 → 只看该日） | **日历 Tab**：月历 + 选中日明细 |
| 统计（日报/周报/月报/年报） | **统计 Tab**：四周期 + 双环 + 排行榜 |
| 我的（设置、备份、分类） | **我的 Tab**：平台/分类、流水计划、CSV 备份 |

### 2.3 交互原则（沿用 TimeBook v4.x）

- **手机优先**，PC 宽屏只做适度拉宽，不另做一套逻辑。
- **底栏固定四格**，顺序固定：`首页 | 日历 | 统计 | 我的`。
- **左滑 / 右滑**（若明细行支持编辑）：右滑删除区**整条红色**，左滑编辑区**整条蓝色**（无留白，与 TimeBook v4.23+ 一致）。
- **日历**：月份标题**几何居中**（‹ 年月 ›）；点年月 → **双列滚轮**选年/月；**今天**格子显示「今」+ 高亮，选中日另用强调色区分。
- **切换 Tab 时**主滚动区回顶，避免顶栏被滚出视口。

## 三、信息架构（目标态）

```
┌─────────────────────────────────────┐
│  App 顶栏（可选精简：仅标题 + 状态）   │
├─────────────────────────────────────┤
│                                     │
│         【当前 Tab 页面内容】         │
│                                     │
├─────────────────────────────────────┤
│  首页  │  日历  │  统计  │  我的     │  ← 固定底栏 4 项
└─────────────────────────────────────┘
```

| Tab | ID 建议 | 职责 |
|-----|---------|------|
| 首页 | `home` | 今日/出车概览、快捷记一笔、核心指标卡片、**仅今日**流水 |
| 日历 | `calendar` | 月历、选日期、**该日**收支明细（同 TimeBook 日历页） |
| 统计 | `stats` | 日/周/月/年切换、**收入环+支出环**、排行与图表 |
| 我的 | `mine` | 原「设置」全部迁入 + 备份恢复 + 关于 |

**禁止**：在首页底部再嵌一整块月历（v4.20 已证伪）；日历只在「日历」Tab。

## 四、分 Tab 详细设计

### 4.1 首页（Home）

**定位**：出车中的「驾驶舱」——只看**今天**（或「当前出车日」），与 TimeBook「流水页仅今日」一致。

**建议模块（自上而下）**：

1. **今日摘要卡**（保留现有 5 指标中的核心，可折叠次要项）  
   - 今日收入 / 今日支出 / 今日结余  
   - 可选：今日工时、今日里程（次要，字号略小）

2. **快捷操作**（可选）  
   - 「记收入」「记支出」或平台一键（滴滴/美团等）  
   - 风格：圆角卡片按钮，勿与 TimeBook 机械键帽混用（本产品偏财务，可保持现有紫渐变主色）

3. **今日流水列表**  
   - 行结构：时间 | 平台或分类 | 金额 | 备注  
   - 收入绿色、支出红色，与现网一致  
   - **不展示**月历组件

4. **本周/本月目标进度（可选）**  
   - 若保留「流水计划」，在首页用**细进度条**即可；详细编辑放「我的」

**不应出现**：设置齿轮、月度统计大图、日历网格。

---

### 4.2 日历（Calendar）

**定位**：TimeBook `page-calendar` 的收支版。

**布局**：

```
┌──────────────────────────────┐
│  ‹    2026年5月（可点）    ›   │  ← 月份居中，无「今」按钮
├──────────────────────────────┤
│  一  二  三  四  五  六  日    │
│  …  每日格：日期 + 小字收入绿   │
│      + 小字支出红 + 有账圆点   │
│  「今」格：青绿底 + 今          │
│  选中日：紫底（非今日）         │
├──────────────────────────────┤
│  5月21日 星期四               │  ← 选中日标题
│  收 xxx  支 xxx  余 xxx        │  ← 当日汇总一行
├──────────────────────────────┤
│  【当日收支明细列表】           │  ← 与首页同款卡片
└──────────────────────────────┘
```

**月历格内信息**（延续现网优点）：

- 公历日期  
- `+收入` 小字（绿）、`-支出` 小字（红）  
- 有记录日期底部圆点（今日/选中日上圆点改白色）

**交互**：

- ‹ › 翻月；点「2026年5月」→ 底部弹出 **年 | 月 双滚轮** + 取消/确定（参考 TimeBook v4.22，勿用系统下拉框）。
- 点某一天 → `viewDate` 更新，下方列表只显示该日（历史日不可选未来）。
- 切换进日历 Tab → 主区域 `scrollTop = 0`。

---

### 4.3 统计（Stats）

**定位**：TimeBook `page-report` 的收支版 + **双环图**替代「时间双环」。

#### 4.3.1 周期切换（顶部）

与 TimeBook 一致，**分段控件** 四档：

| 周期 | 文案 | 统计窗口含义（建议） |
|------|------|----------------------|
| day | 日报 | 选中日或今日 0:00–24:00 |
| week | 周报 | 自然周（周一–周日）或按用户出车周起算（需产品确认） |
| month | 月报 | 自然月 |
| year | 年报 | 自然年 |

切换周期时，下方所有组件联动刷新。

#### 4.3.2 双环图（核心改版）

**布局**：并排或上下两个环（手机建议 **上下叠放**，PC 可并排）。

| 环 | 含义 | 环心文案建议 | 配色 |
|----|------|--------------|------|
| **收入环** | 当前周期各**收入平台**占比 | 总收入 ¥xxx | 绿色系扇区（各平台可区分色阶） |
| **支出环** | 当前周期各**支出分类**占比 | 总支出 ¥xxx | 红色系扇区（各分类可区分色阶） |

**与 TimeBook 时间环的对齐关系**：

```
TimeBook          →    出车收支
─────────────────────────────────
内环（如 1H 剩余）  →    收入环（本期「进账结构」）
外环（如 24H/日）   →    支出环（本期「花销结构」）
环下 caption       →    「收入」「支出」或平台/分类名
```

**环图旁辅助**（保留现网优点，作环图补充）：

- 平台收入排行列表（滴滴、美团…）  
- 支出分类排行（车租、充电…）  
- 原柱状图可降为 **二级 Tab** 或折叠区，**不以柱图替代双环**

#### 4.3.3 汇总条

环图上方或下方固定一行：

- **收** · **支** · **余**（与现网日历顶汇总一致，颜色绿/红/蓝）

#### 4.3.4 目标进度（可选）

周报/月报时展示「本周目标」「本月目标」进度条（数据来自「我的 → 流水计划」）。

---

### 4.4 我的（Mine）

**定位**：原 **设置页全部迁入**，右上角齿轮取消。

**建议分组**（对应现网设置截图）：

| 分组 | 内容 |
|------|------|
| 收入平台 | 列表 + 排序 + 编辑 + 添加（滴滴/美团/曹操/T3/其他） |
| 支出分类 | Tab 切换「收入平台 / 支出分类」或分两块卡片 |
| 流水计划 | 本周目标、本月目标金额，保存按钮 |
| 数据 | 导出 CSV、从 CSV 恢复、备份提醒开关 |
| 关于 | 版本号、隐私说明入口（云端上线前可先占位） |

**样式**：白卡片 + 圆角 + 主色紫渐变按钮，与现网设置页一致，仅**入口位置**改为底栏「我的」。

## 五、视觉与组件规范（摘要）

| 项目 | 规范 |
|------|------|
| 主色 | 保留现网紫蓝渐变顶栏；统计/按钮可与 TimeBook 靛蓝 `#6366f1` 共存，**不必强行改色** |
| 收入数字 | 绿色 `#10b981` 或现网绿 |
| 支出数字 | 红色 `#ef4444` 或现网红 |
| 结余 | 蓝色或深灰，正数强调 |
| 底栏 | 高 64px + safe-area；选中项主色 + 未选 `#94a3b8` |
| 卡片 | 白底、圆角 16–20px、浅边框 `#f1f5f9` |
| 字体 | 系统 sans；金额可用等宽 `font-mono` |

## 六、数据与状态（开发须知）

### 6.1 建议的核心状态

```text
viewDate          // 日历/统计选中的查看日 YYYY-MM-DD
calendarViewYear
calendarViewMonth
statsPeriod       // 'day' | 'week' | 'month' | 'year'
activeTab         // 'home' | 'calendar' | 'stats' | 'mine'
platforms[]       // 收入平台配置
expenseCategories[]
records[]         // 收支流水
goals{ week, month }
```

### 6.2 存储（现阶段）

- 与 TimeBook 相同：**浏览器 localStorage** 或小程序本地存储。  
- 「导出 CSV / 从 CSV 恢复」保留在「我的」。  
- **云端账号同步**：下一阶段，见 TimeBook 规划，不在本文实现范围。

### 6.3 首页 vs 日历 的数据规则

| 页面 | 流水范围 |
|------|----------|
| 首页 | **固定今天**（不受 `viewDate` 影响） |
| 日历 | **`viewDate` 当日** |
| 统计 | **当前周期聚合**（与 `viewDate` 锚定周/月/年） |

- [ ] 底栏仅 4 项：首页、日历、统计、我的

- [ ] 统计 Tab：日报/周报/月报/年报 + **收入环 + 支出环**  
- [ ] 切换 Tab 主区域回顶

# 浏览器打开 http://localhost:8080/index.html
